# Architecture Decision Records

Use an ADR for decisions that materially affect architecture, security, deployment, data ownership, or long-term maintainability.

## Status vocabulary

- Proposed
- Accepted
- Superseded
- Rejected

## Naming

`NNNN-short-decision-title.md`

## Template

Copy `0000-template.md` for each new decision.

Do not edit an accepted ADR to rewrite history. Create a new ADR that supersedes it.
